# C++ 迴圈快速入門

## 核心概念
迴圈是讓電腦重複執行相同工作的方法。`for` 適合已知或容易描述重複次數的情況，`while` 適合依照條件決定何時停止。

## 重點整理
- `for` 通常包含初始化、繼續條件與每輪更新。
- `while` 會在每次執行前檢查條件。
- `break` 可以提前離開迴圈；`continue` 則跳過當輪剩餘內容。

## 小例題
印出 1 到 5 的整數：

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " ";
    }
    return 0;
}
```

輸出結果是 `1 2 3 4 5`。

## 常見錯誤
把 `i <= 5` 寫成 `i < 5`，就只會印到 4。迴圈條件的等號會改變執行次數。
